# 自然言語で操作するCRANE+ V2

フィジカルAI講座の最終課題。LLMが自然言語の指示と現在の関節状態から操作手順を考え、MCP・ROS 2を通じてGazebo内のCRANE+ V2を動かすことを目指します。

## 現在の状態

構成検討を完了し、実装準備中です。制御コードや動作確認はまだありません。

## 想定する機能

- 現在の関節状態の取得
- 関節の目標角度と動作時間を指定した移動
- グリッパの開閉
- 複数操作の組み合わせと、追加指示による変更
- 指令の検査、到達確認、実行結果の記録

追加学習は行わず、学習済みLLMの推論を使用する予定です。使用モデル、導入手順、実行方法、評価結果は実装に合わせて追記します。
